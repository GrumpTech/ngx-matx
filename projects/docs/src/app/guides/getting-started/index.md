ngx-matx extends [Angular Material](https://material.angular.dev) with additional components. This guide walks you through the installation.

## Prerequisites

- Angular 21 or later
- Angular Material 21 or later

If your project doesn't use Angular Material yet, add it first:

```bash
ng add @angular/material
```

## Installation

```bash
npm install @grumptech/ngx-matx
```
